# Takku

Personal macOS app that records meetings, produces a Transcript and a Summary with providers chosen by the user (preferably local or hosted in the EU) and writes the result into an Obsidian Vault. An alternative to Granola for those whose company policy requires EU data residency.

## Language

### Meeting and capture

**Meeting** (`Meeting`):
A call recorded with Takku, from start to stop, or an audio or video file recorded elsewhere and imported. Everything else revolves around it.
_Avoid_: call, session

**Recording** (`Recording`):
The audio of a Meeting, kept outside the Vault for a limited time.
_Avoid_: audio, audio file

**Track** (`Track`):
One of the two audio sources of a Recording: **Me** (microphone) or **Others** (system audio).
_Avoid_: channel, stream

**Segment** (`Segment`):
A portion of a Track saved in its own file, with its start time relative to the start of the Meeting.
_Avoid_: chunk, block, piece

**Mark** (`Mark`):
A moment the user marks as important while recording (⌃⌥⌘M). It stars the Transcript paragraph it falls in, and the Summary gives that paragraph priority.
_Avoid_: bookmark, highlight

**Screenshot** (`Screenshot`):
An image of the active window the user takes while recording (⌃⌥⌘S); the whole screen when that window is in full screen or there is none. Taking one also makes a Mark at the same moment. It is kept in the Vault and shown in the Transcript and the Meeting note; the Summary model never sees it.
_Avoid_: capture (that is the audio), snapshot, image

**Processing** (`Processing`):
The phase after the stop in which Takku completes the Transcript and generates the Summary. It can fail and be retried.
_Avoid_: post-processing, job

### Outputs

**Transcript** (`Transcript`):
The spoken text of a Meeting, with timestamps and who speaks: Me or a Speaker. It lives in its own file in the Vault.
_Avoid_: transcription (for the file)

**Utterance** (`Utterance`):
A stretch of speech recognised in a Track, with start and end relative to the start of the Meeting. Consecutive Utterances of the same Track and Speaker form a paragraph of the Transcript.
_Avoid_: segment (that is something else), sentence, chunk

**Speaker** (`Utterance.speaker`):
One of the voices told apart in the Others Track, shown as *Speaker 1*, *Speaker 2*… in the order they first speak. The same number is the same voice within one Meeting only; it says nothing about who the person is. An Others Utterance that cannot be given a Speaker stays *Others*. The user can name a Speaker in the Meeting note (`speakers`): the Transcript then shows *Name (Speaker N)*.
_Avoid_: participant (the people in the Meeting, Me included), voice

**Known voice** (`VoiceLibrary.Voice`):
The voice of a person the user named as a Speaker, remembered on the Mac to suggest the same name for a Speaker of a later Meeting. Only with voice recognition on, which is off by default: a voice is biometric data. Each name keeps its voice from its 5 latest Meetings; it can be forgotten in Settings.
_Avoid_: voiceprint, enrollment, profile (that is the Provider's)

**Invited participants** (`participants`):
The people invited to the calendar event of a Meeting, written in the Meeting note at the start. Who was invited, not who spoke: they help the Summary name the Speakers.
_Avoid_: attendees, guests

**Summary** (`Summary`):
The structured summary of a Meeting, generated by applying a Template to the Transcript and the Personal notes.
_Avoid_: recap, minutes

**Personal notes** (`PersonalNotes`):
The notes the user writes by hand during the Meeting. They guide the Summary and Takku never changes them.
_Avoid_: user notes

**Meeting note** (`MeetingNote`):
The file in the Vault holding the Summary, the Personal notes and the link to the Transcript.
_Avoid_: summary file, document

**Managed section** (`ManagedSection`):
The part of the Meeting note that Takku may rewrite. Everything else belongs to the user.

**Template** (`Template`):
A file in `~/.takku/templates/` that defines the structure and instructions of the Summary for a kind of Meeting.
_Avoid_: model (ambiguous with the AI model), prompt

**Vocabulary** (`Vocabulary`):
A file in `~/.takku/` listing the terms (names, acronyms, technical words) that speech recognition tends to get wrong. Each entry is the correct term, optionally with the variants usually heard instead and a short description of what it is. It applies to every Meeting.
_Avoid_: dictionary, glossary

**Summary log** (`SummaryLog`):
The copy, in `~/.takku/summary-log/`, of every request Takku sent the model for a Summary and of every reply, as they went: one entry per Summary, Retry and Regeneration included, also when the Summary failed. The user reads it to improve the Templates; Takku writes it and never reads it back (ADR 0010).
_Avoid_: history, trace, prompt log

**Regeneration** (`Regeneration`):
Producing a new Summary for a Meeting already processed from the current Transcript in the Vault, without using the audio. It is what *Regenerate Summary* does, even while the Recording is still available.

### Providers

**Role** (`Role`):
What a Provider is used for: **transcription** or **summary**. In v1 only the summary Role is configurable; transcription is always local.

**Provider** (`Provider`):
A local or remote service that performs a Role, chosen by the user: preferably local or processing data inside the EU.
_Avoid_: backend, API, vendor

**Provider profile** (`ProviderProfile`):
A named configuration of a Provider (endpoint, credentials, model and, for the Summary, how much the model reasons and any Extra parameters) that the user selects for a Role. For the Summary the user can also choose none (*Transcript* in the menu): the Meeting then gets only its Transcript, with no Summary and no Template.
_Avoid_: preset, account

**Extra parameters**:
Request parameters the user writes in a Provider profile, sent to the Provider as written and in place of what Takku would send for the same key. They hold what Takku does not know about a model, such as how it wants to be asked to reason.
_Avoid_: custom body, overrides, advanced settings

**Vault** (`Vault`):
The Obsidian folder where Takku writes Meeting notes and Transcripts, in Obsidian's format (frontmatter, `[[links]]`) whatever the Editor.

**Editor** (`Editor`):
The app the user chooses to open the Meeting notes and Transcripts of the Vault: Obsidian or another Markdown editor. Obsidian unless the user chooses otherwise.
_Avoid_: viewer, opener, note app

**Hook** (`Hook`):
An executable written by the user, in `~/.takku/hooks/`, that Takku runs when a Meeting completes Processing, to take the Meeting note and the Transcript elsewhere.
_Avoid_: plugin, integration, webhook
